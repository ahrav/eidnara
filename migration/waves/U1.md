# Wave U1: repository bootstrap

## Source

The host source repository at `b5273dcb2a76fb0ffe9800b7c54bbd8d1ad98825`.
U1 carried one document from it. Everything else in the wave was authored
here.

## Ported

- `docs/properties/METHOD.md`, the property-record contract. It is adapted
  from the host source's method document: four field-format lines that used
  an em dash as the separator between an enumerated field head and its note
  use a spaced hyphen instead, and the formatting rule names that convention.
  No other prose changed.

## Authored

- Workspace and toolchain files: `Cargo.toml`, `rust-toolchain.toml`,
  `rustfmt.toml`, `package.json`, `tsconfig.json`, `.gitignore`, `LICENSE`,
  `NOTICE`, `README.md`.
- `.github/workflows/ci.yml` with the repository gates.
- `docs/runbooks/architecture-review.md`, the pre-port and post-integration
  review procedure for product-source waves.
- `docs/properties/README.md`, the catalog layout and coverage rules.

## Dropped

U1 also authored a set of migration controls. All of them compared this tree
against the source repositories. They are deleted:

- the registry of frozen identities, `migration/registry.json`;
- the upstream-readiness record, `migration/upstream-readiness.json`;
- the owners record, `migration/owners.json`;
- the crate-name collision check, `migration/waves/U1/crate-name-collision-check.json`;
- the wave receipt, `migration/waves/U1/receipt.json`;
- the wave waiver record, `migration/waves/U1/waivers.json`;
- the TypeScript checker and its tests, `scripts/eidnara-migration/check.ts`
  and `scripts/eidnara-migration/check.test.ts`;
- the registry audit and its tests, `scripts/eidnara-migration/registry-audit.ts`
  and `scripts/eidnara-migration/registry-audit.test.ts`;
- the property-index generator, its tests, and its output,
  `scripts/eidnara-migration/generate-property-index.ts`,
  `scripts/eidnara-migration/generate-property-index.test.ts`, and
  `docs/properties/shared-primitives/index.json`;
- the release gate record, `release/registry-gate.json`.

Two `git grep` steps in CI now cover the two invariants that remain (no
predecessor token outside `docs/plans/`, no schema-migration identifier
outside test files and prose), and each wave leaves a note like this one
instead of a receipt.

## Renamed

Nothing. The wave carried no code.
