# Fault map: fold authority (M1 and M2)

Each row names a fault or enabling state, its occurrence marker, the
witness that constructs it, and the records it serves. An occurrence marker
is the independent enabling-state assertion that proves the fault or state
was constructed before the safety check fired; per METHOD's coverage-check
rules it asserts preconditions, never the violation, and fires on a correct
implementation. Marker names are constant and unique (`FA-FM01` to
`FA-FM42`, with gaps where a group needed fewer rows). A green safety
assertion without its marker is not coverage.

The repository has no campaign runtime. The one `sometimes` record (FA-E06)
and a marker here mean that a named deterministic test constructs the state
once per suite run and asserts it before its verdict. No `FA-FMnn` token
appears in code: the link between a marker and its test exists only in this
file. `missing` means no test constructs the state yet; `catalog.md` names
the owner, or marks it unowned.

`file:line` is at `0ff62b29a` unless a row names another tree.
