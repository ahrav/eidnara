# `hard-bust-drains-deferred-work`

- **Discovery:** cache-stability state-machine pass, coordinator drain rule.
- **Primary evidence:** `step_hard` (`crates/cache-stability/src/lib.rs:254-283`) clears the frozen set and applies the rendered units followed by the drained `pending_changes`, skipping any deferred copy of a key the render produced, so a key the render no longer produces leaves the set; assigns `boundary_id` when `new_boundary_id` is `Some`; and clears `reconcile_pending` when the pass mints a boundary, matches the existing boundary, or has no current boundary (`!minted && !boundary_match && !boundary_id.is_empty()` keeps it). `CoreState::step` removes episode units before dispatch, so a `Hard` with `run_started` retains only lineage units.
- **Existing evidence:** `hard_drains_pending_changes_into_the_bust` (`crates/cache-stability/src/lib.rs:455-488`) queues a drop through a defer, confirms it is absent from the prefix, then busts hard with a baseline that omits it and asserts the drain, the mint, the prefix, and the cleared flag; `hard_prefers_rendered_units_over_deferred_copies_of_the_same_key` (`crates/cache-stability/src/lib.rs:426-453`) queues a stale copy of `m0`, re-renders `m0` on the HARD, and asserts the rendered bytes are frozen; `hard_drops_frozen_keys_the_render_no_longer_produces` (`crates/cache-stability/src/lib.rs:403-424`) renders only `m0` over a frozen `m0`+`m1` and asserts `m1` and its bytes are gone; `hard_without_mint_on_absent_boundary_keeps_reconcile_pending` (`crates/cache-stability/src/lib.rs:719-754`) asserts that a `Hard` with no mint at an absent anchor leaves the flag set.
- **Failure scenario:** a `Hard` that freezes only its rendered units leaves the queued drop pending forever, so the rendered context and the recorded state diverge.
- **Timing window:** none.
- **Instrumentation:** none.
- **Audit verdict (U2): pass. The test's rendered baseline deliberately omits the queued unit, so the presence of `[dropped 1]` in the prefix after the bust can only come from the drain.
- **Open-question log:** none.
