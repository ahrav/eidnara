# `defer-pass-replays-frozen-bytes-verbatim`

- **Discovery:** cache-stability state-machine pass over `CoreState::step` and its three arms.
- **Primary evidence:** `step_defer` (`crates/cache-stability/src/lib.rs:221-247`) reads `input.queued` and `boundary_match`; it never reads `rendered_units`, never assigns to a frozen unit's `frozen_payload`, and never reorders `frozen_units`. `version` is incremented only in `step_soft` and `step_hard`. The run boundary is handled before the arm dispatch: `CoreState::step` (`crates/cache-stability/src/lib.rs:182-219`) reads `input.run_started` and, when it is set, retains only `DurabilityClass::Lineage` units in `frozen_units` and `pending_changes`. That filter removes whole units, so on a `run_started` defer `cached_prefix_bytes()` can lose the episode payloads while every retained lineage payload stays byte-identical; on every other defer `cached_prefix_bytes()` is unchanged.
- **Existing evidence:** `defer_does_not_mutate_frozen_bytes_or_render` (`crates/cache-stability/src/lib.rs:369-390`) compares the prefix and the version before and after a matching-boundary defer; `defer_boundary_absent_keeps_bytes_and_sets_reconcile_pending` (`crates/cache-stability/src/lib.rs:431-449`) compares the prefix across an absent-boundary defer; `run_started_keeps_lineage_resets_episode` (`crates/cache-stability/src/lib.rs:692-714`) checks that a `run_started` defer leaves exactly the lineage unit, with its payload byte-identical; `run_started_resets_episode_units_on_every_action` (`crates/cache-stability/src/lib.rs:716-743`) checks that the reset is a property of the run boundary for `SoftPlus`, `Soft`, and `Hard`; every golden vector asserts `cached_prefix_bytes()` after each pass in `run_vector` (`crates/cache-stability/tests/golden_vectors.rs:168-272`); the one vector whose pass carries a `run-started` signal (V9) covers the `run_started` lineage-retention arm, not the unchanged-prefix arm, and `cross_episode_lineage_reproduces_byte_identical` (`crates/cache-stability/tests/golden_vectors.rs:274-322`) pins lineage byte identity across that boundary.
- **Failure scenario:** a refactor that re-renders on defer, or that applies `queued` units into `frozen_units` directly, changes the prefix on a pass that the harness did not render for; a refactor that rewrites a lineage payload during the run-boundary filter changes retained bytes.
- **Timing window:** none; the property is per call.
- **Instrumentation:** none needed; the state is a value.
- **Audit verdict (U2): pass, with the claim scoped. The tests prove prefix and version identity for defers without `run_started`, and lineage-payload byte identity with episode removal for defers with `run_started`; they do not claim an unchanged prefix for every defer. The assertions compare the prefix string, the version number, and the retained payload, none of which derives from the action under test; a `step_defer` that pushed `queued` into `frozen_units` would fail the prefix comparison in `hard_drains_pending_changes_into_the_bust` and the golden vectors with queued units.
- **Open-question log:** none.
