## Observation and judgment contract

Keep these observations separate:

1. **Authored:** original producer output, tier presence, and native source
   identities. A missing tier is not an authored paraphrase.
2. **Parsed/published:** fallback and healed bodies, accepted range, discarded
   range, and durable publication identity. A valid earlier range does not
   grant coverage to a discarded final segment. Fact extraction can reject its
   whole fact set while valid history still publishes; it is not memory admission.
3. **Effective:** selected age/importance tier, pressure demotion, effective
   body source, empty-heading or legacy representation, and omission.
4. **Delivered:** applied recipe and the nonempty correlated provider request,
   including system text, messages, hints, memory, live tail, and tools.

For each material obligation, consume the recovery owner's canonical
**visible**, **discoverable**, or **unavailable** disposition against the whole
invocation. Delivery supplies the effective tier, omitted range, hints, admitted
memory, and raw-tail observations; it does not reimplement that predicate.
Unavailable receives no useful-preservation or recovery credit. The plan permits
acceptance where the scenario explicitly allows unavailable evidence and safe
abstention, but that acceptance is not retained meaning. If the scenario requires
useful retention, losing its only constraint remains a preservation failure even
when the answer avoids harm. Nonmaterial losses must be declared in advance.

Deterministic checks establish identity, rendering, and reached situations.
Semantic checks consume human-reviewed, source-backed judgments over the
actual heading/body, invocation, and answer. They accept paraphrases and reject
changed scope, polarity, status, or evidence strength. String equality and an
optional model judge cannot substitute for that review. Missing review is
unverified, not a passing semantic result.

## Relationships and handoff

- Initial fixture qualification is evaluation-owned. Delivery consumes its
  receipt and owns the per-invocation join used by the four semantic records.
  Neither qualification level proves semantic fidelity.
- Situation coverage guards that prerequisite and the semantic checks against
  vacuity. A missing marker is a setup gap or a reachability regression, not a
  semantic pass and not a proof of failed formal liveness.
- Omission consumes tier, hint, and memory observations. Memory and hints are
  alternative evidence surfaces, not automatic substitutes for missing history.
  The recovery-owned canonical disposition predicate is shared, not copied.
  No dominance between these semantic records is established.
- Reuse existing renderer checks instead of adding generic omission, escaping,
  or budget-mechanism slugs. The R9 record composes existing checks with the
  feature's production-work restrictions. Existing related records include
  [core decay](../../memory-store/catalog.md#core-decay-tier-ladder-monotone-and-archive-agreement),
  [hint fragment reachability](../../daemon/rendering/catalog.md#render-a-hint-fragment-cap-binds-in-a-served-render),
  and [canonical read distinction](../../daemon/transform/catalog.md#canonical-read-staleness-is-distinguishable-from-emptiness).
  Their historical exercise claims are not adopted here.
- Route every active record to `/testing:test-strategy`. Route existing-test
  adequacy to `/testing:invariant-test-review`; route runtime guard strength to
  `/low-level-systems:defensive-assertions-and-invariant-guards`. Use simulation
  only if the chosen test boundary needs scheduling exploration.

There are seven active records: six `always` safety checks and one `sometimes`
umbrella with 14 independently reported situation markers and their required
subcases. None claims formal liveness. Preserve current history and
memory budgets, cache behavior, and admission. Keep semantic judging offline;

publication/serving, then qualify fixture and per-invocation delivery. These
