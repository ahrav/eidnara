# Wave U1: repository bootstrap

## Source

The host source repository at `b5273dcb2a76fb0ffe9800b7c54bbd8d1ad98825`.
U1 carried one document from it. Everything else in the wave was authored
here.

## Ported

- `docs/properties/METHOD.md`, the property-record contract. It is adapted
  from the host source's method document: four field-format lines that used
  an em dash as the separator between an enumerated field head and its note
  use a spaced hyphen instead, and the formatting rule names that convention.
  No other prose changed.

## Authored

- Workspace and toolchain files: `Cargo.toml`, `rust-toolchain.toml`,
  `rustfmt.toml`, `package.json`, `tsconfig.json`, `.gitignore`, `LICENSE`,
  `NOTICE`, `README.md`.
- `.github/workflows/ci.yml` with the repository gates.
- `docs/runbooks/architecture-review.md`, the pre-port and post-integration
  review procedure for product-source waves.
- `docs/properties/README.md`, the catalog layout and coverage rules.

## Dropped

U1 also authored a set of migration controls: a registry of frozen
identities, an upstream-readiness record, an owners record, a crate-name
collision check, a receipt and waiver record for the wave, a TypeScript
checker with its tests, a registry audit, a property-index generator, and a
release gate record. All of them compared this tree against the source
repositories. They are deleted; two `git grep` steps in CI now cover the two
invariants that remain (no predecessor token outside `docs/plans/`, no
schema-migration identifier in non-test code), and each wave leaves a note
like this one instead of a receipt.

## Renamed

Nothing. The wave carried no code.
